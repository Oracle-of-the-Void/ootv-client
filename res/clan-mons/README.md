# Clan mons

The L5R clan mons the card rows draw before a clan's name (game config `clanmons`,
docs/admin/game-config.md). `oracle-ink-outlined/`: ootv-assets `mons/oracle_ink/outlined/`
(the brush mons in clan colour with a light outline), scaled to 48x48. Only the mons of clans
that cards carry are here; another clan is another file and an entry in the config. Another
style is another directory here and a new `path` in the config.
