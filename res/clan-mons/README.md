# Clan mons

The L5R clan mons the card rows draw before a clan's name (game config `clanmons`,
docs/admin/game-config.md). `oracle-plain-color/`: ootv-assets `mons/oracle_plain/color/`
(the flat mons in clan colour), scaled to 48x48. Only the mons of clans that cards carry are
here; another clan is another file and an entry in the config. Another style is another
directory here and a new `path` in the config.
